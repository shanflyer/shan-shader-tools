Shan HLSL adds HLSL language services to CLion, powered by Tim Jones' open-source HlslTools engine.

  • Semantic completion for shader symbols, struct members and built-in functions.
  • Signature help, hover documentation, definition navigation and reference highlighting.
  • Document symbols and Structure navigation.
  • Live syntax and semantic diagnostics for unsaved shader text.
  • The HlslTools formatter, preprocessor-aware semantic colors and inactive-region highlighting.
  • Includes and preprocessor definitions using shadertoolsconfig.json.

Requirements: Windows x64 and CLion 2026.2 build 262.10968.117 or later within the 262 branch. The package includes the local language server and .NET runtime; installing .NET SDK or DXC is not required to use it.

This beta follows the pinned HlslTools engine's language support. Some newer HLSL syntax may be unsupported. Symbol search follows the server's opened-document workspace. Save include files before refreshing dependent shaders. The IDE interface differs from Visual Studio; the VS syntax-tree visualizer is not included.

Free and open source under Apache 2.0 with retained upstream and dependency notices.
