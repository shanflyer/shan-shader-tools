Shan GLSL brings GLSL editing and local shader diagnostics to JetBrains IDEs.

  • Syntax highlighting with configurable GLSL keyword, built-in function and variable colors.
  • Built-in keyword/function completion and identifiers from the current shader.
  • Code folding, brace matching and line/block comments.
  • Live glslang diagnostics for unsaved shader text, shown in the editor and Problems window.
  • Vulkan and OpenGL validation, stage suffix detection, includes and //! / //? comment substitutions.

Requirements: JetBrains IDE 2026.2 build 262.10968 or later within the 262 branch. The beta is tested on Windows x64. Install glslangValidator separately; it is discovered from VULKAN_SDK or PATH, or configured in Settings | Languages & Frameworks | Shan GLSL.

The plugin provides vocabulary/file-identifier completion rather than full GLSL type inference. Validation does not replace your shader build pipeline. Disable other plugins claiming the same file extensions if associations conflict.

Free and open source under MIT. Contains vocabulary from Daniel Scherzer's GLSLhelper with attribution.
