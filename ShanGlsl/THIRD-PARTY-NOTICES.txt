Feature and palette reference
-----------------------------
Daniel Scherzer's GLSL language integration for Visual Studio:
https://github.com/danielscherzer/GLSL
https://marketplace.visualstudio.com/items?itemName=DanielScherzer.GLSL2022
The implementation in this plugin is newly written for IntelliJ Platform.
No Visual Studio extension binaries or C# implementation are bundled.
GLSL category colors and //! / //? conventions follow that reference.
This plugin is not affiliated with or endorsed by the reference project's author.

External tools
--------------
CLion / IntelliJ Platform APIs are compile-only; IDE binaries are not bundled.
glslangValidator is discovered from the user's installation and is not bundled.
